# EVB Text-Lern

Lern-App für das Ensemble der Eibeler Volksbühne: Wähle deine Rolle in «S'Füür vom Schmied» und lerne
deinen Text mit Karteikarten, Sprachausgabe und Hörproben – auf dem iPhone oder Android-Handy, auch unterwegs.

**App öffnen:** <https://defendeggu.github.io/theater-lernapp/>

> **Ziel der Regie:** Ab **Anfang Dezember 2027** probt das Ensemble ohne Textbuch.
> Premiere ist Ende April 2028. Die App richtet ihren Lernplan auf das Textfest im Dezember aus.

---

## Für das Ensemble

### Erste Schritte

1. **Öffnen:** Den Link oben öffnen – auf dem iPhone in **Safari**, auf Android in **Chrome**.
2. **Passwort:** Das Ensemble-Passwort eingeben. Du bekommst es von der Regie.
   Die App merkt es sich auf deinem Gerät. Du musst es nur einmal eingeben.
3. **Rolle wählen:** Tippe auf deine Rolle. Du kannst sie später in den Einstellungen wechseln.
   Wenn du mehrere Rollen lernst, bleibt der Lernstand jeder Rolle erhalten.
4. **Auf den Home-Bildschirm legen** (wichtig!):
   - **iPhone:** In Safari unten auf **Teilen** tippen → **«Zum Home-Bildschirm»**.
   - **Android:** In Chrome oben rechts auf **⋮** tippen → **«App installieren»** oder
     **«Zum Startbildschirm hinzufügen»**.

   Danach öffnest du die App über das Symbol (Amboss mit Funken) wie eine normale App.

> **Warum der Home-Bildschirm wichtig ist:** Safari löscht Daten von Webseiten, die 7 Tage
> nicht benutzt wurden. Als App auf dem Home-Bildschirm gilt das nicht. Sichere trotzdem ab
> und zu deinen Lernstand (siehe unten).

### So funktioniert eine Karte

- **Vorderseite:** der letzte Satz vor deinem Einsatz, z.B. «Karl: Und was hast du gestern gemacht?»
  (erfundenes Beispiel). Mit ▶︎ wird er vorgelesen.
- **Sprich deinen Text** laut oder leise.
- **Umdrehen:** Tippe auf «Umdrehen» oder auf die Karte. Auf der Rückseite steht dein Text,
  Regieanweisungen grau in Klammern.
- **Selbst bewerten:**

  | Knopf | Bedeutung | Was passiert |
  |---|---|---|
  | 🔴 **Nicht gewusst** | Ich wusste den Text nicht | Karte kommt in dieser Runde nochmals und dann wieder oft |
  | 🟡 **Fast** | Ungefähr, mit Fehlern | Karte bleibt auf ihrer Stufe |
  | 🟢 **Gewusst** | Sass! | Karte kommt seltener |

- **Wischen:** links = nächste Karte, rechts = vorherige.

**Hilfestufen** (oben über der Karte, vor dem Umdrehen):
«Stichwort» (nur der Satz davor) · «A b c» (Anfangsbuchstaben jedes Wortes) ·
«Lücken» (jedes 3. Wort fehlt) · «Ganz» (ganzer Text zum Einlesen).

### Lernmodi

| Modus | Wofür |
|---|---|
| **Heute lernen** | Das Wichtigste jeden Tag: fällige Karten und ein paar neue. Am besten täglich 10–15 Minuten. |
| **Chronologisch** | Durchs Stück der Reihe nach, ab einer beliebigen Szene. Die App merkt sich, wo du warst. |
| **Zufall** | Gemischt aus dem ganzen Stück, einem Akt oder einer Szene. |
| **Schwache Karten** | Nur die Karten, die noch nicht sitzen. |
| **Hörprobe** | Eine ganze Szene zum Anhören – die anderen Rollen sprechen, bei deinem Einsatz hält die App an. Ideal mit Kopfhörern. |
| **Statistik** | Wie viel sitzt schon, pro Akt und pro Szene. |

Die Akte haben eigene Farben: **Akt 1 gelb**, **Akt 2 orange**, **Akt 3 rot** – wie ein Feuer,
das immer heisser brennt.

### Der Lernplan bis zum Textfest

Die App kennt vier Phasen. Die aktuelle Phase siehst du auf der Startseite.

| Phase | Zeitraum (Standard) | Was die App macht |
|---|---|---|
| **Kennenlernen** | bis Ende Mai 2027 | Stück und Ablauf kennenlernen, chronologisch lesen |
| **Festigen** | Juni bis Anfang Oktober 2027 | täglich «Heute lernen», gern mit Anfangsbuchstaben |
| **Endspurt** | 8 Wochen vor dem Textfest | jede Karte kommt spätestens nach 3 Tagen wieder |
| **Text halten** | Dezember 2027 bis Premiere | Text wach halten: Hörproben, schwache Karten |

Die Daten (Textfest, Premiere) lassen sich in den Einstellungen anpassen.

### Hörprobe und Stimmen

Die App liest die anderen Rollen mit Frauen- und Männerstimmen vor. Es gibt keine Stimme für
Luzerner Dialekt – eine hochdeutsche Stimme liest den Dialekt etwas holprig, aber verständlich.

**Frauen- und Männerstimme auf dem iPhone laden** (einmalig, kostenlos):
*Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch* →
je eine **Frauenstimme** (z.B. Anna) und eine **Männerstimme** (z.B. Markus oder Yannick) laden,
am besten die Variante **«Erweitert»**. Danach die App neu öffnen.

**Android:** *Einstellungen → System (oder Bedienungshilfen) → Sprachen → Text-in-Sprache-Ausgabe* →
bevorzugtes Modul **«Sprachausgabe von Google»** → Zahnrad → **Sprachdaten installieren** →
**Deutsch (Deutschland)**. Danach Chrome ganz schliessen und die App neu öffnen. Android verrät oft
nicht, ob eine Stimme weiblich oder männlich ist – ordne die Stimmen dann unter
*Einstellungen → Stimmen → Stimmen zuordnen* als «Frau» oder «Mann» zu.

Fehlt eine Stimme, verstellt die App die vorhandene und zeigt einen Hinweis.
Unter **Einstellungen → Stimmen** kannst du:

- jede Figur probehören, Stimme und Tonhöhe ändern,
- das Sprechtempo anpassen,
- **automatisches Vorlesen** einschalten: Stichwort vorlesen → Pause zum Sprechen → Karte dreht
  sich von selbst um (auch über «🔈 Auto» oben auf der Karte).

**Gesperrter Bildschirm:** iPhone und Android halten die Sprachausgabe an, wenn das Gerät gesperrt
wird oder der Browser in den Hintergrund geht. Während einer Hörprobe hält die App den Bildschirm deshalb wach.
Mit Kopfhörern: iPhone entsperrt lassen und z.B. in die Tasche stecken.

### Lernstand sichern

*Einstellungen → Lernstand sichern* → «Nur [Rolle] sichern» oder «Alle Rollen sichern».
Über das Teilen-Menü in «Dateien» ablegen oder dir selbst mailen. Die Datei enthält nur deinen
Lernstand, keinen Stücktext. Mit «… laden» holst du ihn zurück (z.B. auf ein neues iPhone).
Beim Laden wird zusammengeführt – pro Karte gilt der neuere Stand.

### Häufige Fragen

- **Die App fragt wieder nach dem Passwort.** Es gibt eine neue Version des Textes oder ein neues
  Passwort. Einfach nochmals eingeben – dein Lernstand bleibt.
- **Der Text einer Karte hat sich geändert.** Wenn die Regie den Text ändert, kommt die Karte
  automatisch zurück auf Stufe 1, damit du die neue Version lernst. Alle anderen Karten behalten
  ihren Stand.
- **Ich sehe noch die alte Version.** Die App schliessen und neu öffnen (eventuell ein paar Minuten warten).
- **Ich habe zwei Rollen.** Rolle in den Einstellungen wechseln; jede Rolle hat ihren eigenen Lernstand.
- **Funktioniert es auch auf Android?** Ja, in einem aktuellen **Chrome** (auch Samsung Internet
  und Firefox). Installieren über ⋮ → «App installieren». Stimmen siehe oben.
- **Und am Computer?** Ja, in einem aktuellen Browser (Chrome, Edge, Safari, Firefox).
  Tastatur: Leertaste = umdrehen, 1/2/3 = Ampel, ←/→ = blättern, V = vorlesen.

## Für die Betreuung (Technik)

### Überblick

```
input/textbuch.pdf ─► tools/parse.py ─► data/private/stueck.json ─► tools/review.py ─► review.html
                       (+ korrekturen.json)       │                     (Kontrolle von Hand)
                                                  ▼
                 data/private/ablauf.json ─► tools/encrypt.mjs (Passwort) ─► public/data/stueck.enc
                                                                                   │
                      GitHub Actions (Tests) ─► GitHub Pages ─► Safari / Home-Bildschirm
```

- Vanilla HTML/CSS/JavaScript (ES-Module), kein Framework, kein Build-Schritt.
- Fortschritt lokal im Browser (IndexedDB, pro Rolle), Einstellungen in `localStorage`.
- Sprachausgabe über die Web Speech API, Zuteilung der Stimmen in `public/js/voices.js`.
- Plan und Regeln: [docs/PLAN.md](docs/PLAN.md) · Hinweise für die Entwicklung: [CLAUDE.md](CLAUDE.md)

### Der Stücktext ist geschützt

Das Stück ist unveröffentlicht und das Repo ist öffentlich. Deshalb:

- `input/` (PDF) und `data/private/` (Klartext, Review) sind in `.gitignore` und kommen **nie** ins Repo.
- Im Repo liegt nur `public/data/stueck.enc`: AES-GCM 256, Schlüssel per PBKDF2-SHA256 mit
  600 000 Iterationen, zufälliger Salt und IV. Entschlüsselt wird im Browser.
- Vor jedem Commit: `git status` prüfen und `python tools/check_klartext.py` laufen lassen.
  Der CI-Workflow bricht ab, wenn private Dateien im Repo landen.
- `noindex` und `robots.txt` halten Suchmaschinen fern.

Das ist kein Hochsicherheits-Schutz, verhindert aber, dass das Stück offen im Netz steht.

### Daten aufbereiten oder aktualisieren

Voraussetzungen: Python 3.12+ mit `pip install pdfplumber pytest`, Node.js 22+.

```sh
# 1. Neues Textbuch nach input/textbuch.pdf legen, dann parsen
python tools/parse.py               # -> data/private/stueck.json (wendet korrekturen.json an)

# 2. Kontrollieren
python tools/review.py              # -> data/private/review.html im Browser öffnen
#    Fehler in data/private/korrekturen.json eintragen und Schritt 1 wiederholen.
#    Kurzfassungen der Szenen stehen in data/private/ablauf.json.

# 3. Verschlüsseln (fragt das Passwort verdeckt ab, zweimal)
node tools/encrypt.mjs              # -> public/data/stueck.enc

# 4. Prüfen und veröffentlichen
python tools/check_klartext.py
git add public/data/stueck.enc && git commit -m "Daten: neues Textbuch" && git push
```

`korrekturen.json` (Beispiel mit erfundenen IDs):

```json
{
  "figuren":  { "erzaehler": { "geschlecht": "m" } },
  "repliken": { "9.9-012": { "sprecher": ["karl", "mona"], "erwartet": "Gueten Obig" } },
  "szenen":   {}
}
```

`erwartet` ist optional: Steht dieses Textstück nicht mehr in der Replik (neues Textbuch),
meldet der Parser eine Warnung statt die Korrektur blind anzuwenden.

**Lernstand bei Textänderungen:** Jede Replik hat eine feste ID (Szene + Nummer) und einen Hash
über den Text. Geänderte Repliken kommen in der App zurück in Fach 1, alle anderen behalten
ihren Stand. Achtung: Wird eine Replik eingefügt oder gelöscht, verschieben sich die Nummern
danach in derselben Szene.

### Passwort wechseln

`node tools/encrypt.mjs` mit dem neuen Passwort ausführen, committen, pushen. Beim nächsten
Öffnen fragt die App alle nach dem neuen Passwort; der Lernstand bleibt erhalten.

### Entwickeln

```sh
node --test test/*.test.mjs         # Logik: Karten, Lernkartei, Hilfen, Stimmen, Verschlüsselung
python -m pytest -q test            # Parser (mit erfundenen Beispielseiten)
python -m http.server 8000 -d public   # App lokal unter http://localhost:8000/
```

Tests verwenden nur erfundene Figuren und Sätze (`test/fixtures/demo.mjs`), nie Text aus dem Stück.

| Ordner | Inhalt |
|---|---|
| `tools/` | Parser, Review, Verschlüsselung, Klartext-Prüfung, `make_icons.py` (App-Icons) |

| `docs/PLAN.md` | verbindlicher Plan mit Datenmodell und Meilensteinen |
