# theater-lernapp

Lern-App für die Eibeler Volksbühne: Rolle wählen, Text mit Karteikarten lernen, Stichworte
hören, Ablauf üben. Läuft im Browser auf dem iPhone (später auch als App auf dem Home-Bildschirm).

Stand: **M0 – Aufbereitung** (Parser, Review, Verschlüsselung). Die App selbst folgt ab M1.
Plan: [docs/PLAN.md](docs/PLAN.md) · Hinweise für die Entwicklung: [CLAUDE.md](CLAUDE.md)

Der Stücktext ist nur verschlüsselt im Repo (`public/data/stueck.enc`), das Textbuch selbst nie.
Die ausführliche Anleitung fürs Ensemble kommt mit M5.
